# 사진 넣는 곳

파일명은 자유입니다. 폴더에 넣기만 하면 빌드할 때 자동으로 인식됩니다.
정렬은 파일명 자연 정렬 순서를 따릅니다. (`img2.jpg` 가 `img10.jpg` 보다 앞)

| 폴더 | 용도 | 장수 |
| --- | --- | --- |
| `gallery/` | 갤러리 격자 + 첫 화면 대표 사진 | 자유 |
| `story/` | 우리 이야기 | 글 개수만큼 |
| `location/` | 약도 | 1장 (없으면 지도 영역이 숨겨짐) |

지원 확장자: jpg, jpeg, png, webp

## 첫 화면 대표 사진

별도 폴더를 쓰지 않고, `gallery/` 안의 파일 하나를 지정합니다.
`src/config/invitationConfig.js` 의 `mainPhoto` 에 파일명을 적으세요.

```js
mainPhoto: 'trapi12.jpg',
```

사진이 화면에 꽉 차게 잘리므로, 어느 부분을 보여줄지 따로 지정할 수 있습니다.

```js
mainPhotoPosition: '52% 50%',
```

`X% Y%` 형식이고 기본 가운데는 `50% 50%` 입니다.
X 를 키우면 사진이 왼쪽으로, Y 를 키우면 위로 움직입니다.

## 카카오톡 썸네일만 예외

`public/og.jpg` 에 두고, `index.html` 의 `og:image` 주소를 맞춰주세요.
카카오톡은 링크를 읽을 때 JavaScript 를 실행하지 않아 빌드된 경로를 알 수 없습니다.
