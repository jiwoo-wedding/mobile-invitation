# public

빌드할 때 **가공하지 않고 그대로 복사되는** 파일만 둡니다.
파일명에 해시가 붙지 않아 주소를 미리 알 수 있는 게 특징입니다.

현재 필요한 건 딱 하나입니다.

| 파일 | 용도 | 권장 크기 |
| --- | --- | --- |
| `og.jpg` | 카카오톡 · SNS 공유 썸네일 | 1200×630px |

## 왜 여기에만 둬야 하나

카카오톡은 링크를 읽을 때 JavaScript 를 실행하지 않고 `index.html` 만 정적으로 읽습니다.
그래서 썸네일 주소를 HTML 에 문자로 박아둬야 하는데,
`src/assets/` 에 넣으면 Vite 가 `og-a1b2c3.jpg` 처럼 해시를 붙여서 주소를 미리 알 수 없습니다.

썸네일을 안 쓸 거라면 이 폴더와 `index.html` 의 `og:image` 줄을 함께 지워도 됩니다.
그 경우 카카오톡에서 이미지 없이 제목과 설명만 보입니다.

나중에 커스텀 도메인을 쓰거나 `favicon.ico`, `robots.txt` 를 넣을 때도 이 폴더를 씁니다.

갤러리 · 우리 이야기 · 약도 사진은 `src/assets/` 에 넣으세요.
