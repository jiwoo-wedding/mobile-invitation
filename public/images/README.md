# 사진 넣는 곳

| 폴더 | 용도 | 파일명 | 권장 비율 |
| --- | --- | --- | --- |
| `hero/` | 메인 대표 사진 | `1.jpg` | 3:4 세로 |
| `story/` | 우리 이야기 사진 | `1.jpg`, `2.jpg` ... | 자유 |
| `gallery/` | 갤러리 사진 | `1.jpg`, `2.jpg` ... | 1:1 정사각형 |
| `location/` | 약도 | `1.jpg` | 자유 |
| `og/` | 카카오톡 공유 썸네일 | `1.jpg` | 1200×630px |

## 규칙

- 파일명은 반드시 소문자 `.jpg` 입니다. `1.JPG` 는 다른 파일로 취급됩니다.
- 아이폰 HEIC 사진은 확장자만 바꾸면 안 되고, JPG 로 **변환**해야 합니다.
- 장당 500KB~1MB 이하로 압축하면 로딩이 빨라집니다.
- 사진 장수를 바꾸면 `src/config/invitationConfig.js` 의 `photos` 값도 함께 고치세요.

## 한글 파일명을 쓰지 않는 이유

`갤러리 1.jpg` 처럼 한글과 공백이 들어간 파일명은 URL 인코딩 과정에서
브라우저·서버마다 다르게 해석돼 사진이 깨지는 일이 잦습니다.
숫자 파일명으로 통일하면 사진을 추가·교체할 때 코드를 고칠 필요도 없습니다.
